# Reference values

`thesis_table_5_2.csv` is transcribed by hand from Table 5-2 of the MSc thesis
("Summary of mini-CPT results"). Change columns are the thesis's own
percentages relative to the uncontaminated soil of the same clay content.
The thesis does not document how these values were computed from the raw
forces; `src/run_qc.py` compares them with values recomputed from the raw data.
